# Mini Uber – Ride Sharing Management System

This is a C++ console-based project that simulates a basic ride-sharing system like Uber.
It is created using Data Structures concepts.

## Features
- Add drivers
- Add riders
- Book rides
- Display ride details

## Data Structures Used
- Arrays
- Linked Lists
- Queues
- Structures

## How to Run
1. Open Project.cpp in a C++ compiler (Dev C++, Code::Blocks, or VS Code)
2. Compile and run the file
3. Follow the on-screen menu options
